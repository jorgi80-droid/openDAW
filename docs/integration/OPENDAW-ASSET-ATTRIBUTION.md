# StudioWave asset attribution

This branch contains selected user-interface assets from openDAW, an open-source DAW licensed under AGPL-3.0-or-later.

Source repository: https://github.com/andremichelle/openDAW
Assets copied for this project: `favicon.svg`, `favicon-live.svg`, `empty.svg`, and `grid16.svg` from `packages/app/studio/public`, plus the compact timeline style references `TimeAxis.sass` and `Timeline.sass` as documentation/reference files. These style references are not imported into the Playlist layout, to preserve the existing Timeline layout.

See the root `LICENSE` file for openDAW's AGPL-3.0-or-later terms. Font assets in the Android build are fetched from openDAW; their own distribution terms should be kept with the font files when bundled.
